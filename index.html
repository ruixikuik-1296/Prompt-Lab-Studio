Getting Started

          
Use the Menu button to switch between Prompt Editor, Prompt Cleaner, and Prompt Tagger. The other listed tools are not implemented yet.

        

        

          
Prompt Editor

          
    
            
  • Enter or edit prompt text in the editor. Validation checks for unmatched parentheses and does not modify your text.
    • 
            
  • Undo and Redo move through your editing history. Starting a new document resets that document's history.
    • 
            
  • Use Danbooru Tag Search to find tags. Select a result to insert it at the current cursor position.
    • 
            
  • Save JSON to preserve the document title and prompt; Export TXT to save prompt text only; Open File accepts JSON and TXT files.
    • 
          

        

        

          
Prompt Cleaner

          
    
            
  • Analyze the prompt, then review the output. Switch between marked preview and clean output.
    • 
            
  • Click a tag to add it to Blocked Terms. Choose Exact or Fuzzy matching for each term.
    • 
            
  • Copy cleaned result copies the clean text. Put in Prompt Editor asks for confirmation before replacing the editor content.
    • 
            
  • If the editor prompt changed after analysis, analyze again before applying the result.
    • 
          

        

        

          
Prompt Tagger

          
    
            
  • Select, drop, or paste an image, then choose Generate tags. Image optimization is enabled by default and can be turned off.
    • 
            
  • The image is sent to the public PixAI Tagger Demo for processing.
    • 
            
  • Adjust category confidence thresholds, use feature filters, and select the tags you want. Filters and thresholds affect which tags are included in output.
    • 
            
  • Use the output controls to sort and format tags. Copy all selected copies the selected tags; Put in Prompt Editor (overwrite) asks before replacing the editor content.
    • 
          

        

        

          
Privacy and Storage

          
Your draft and preferences are stored in this browser. Tagger images are sent to the public PixAI service, and Danbooru searches contact the Danbooru API. Avoid using private content unless you are comfortable with these services.
